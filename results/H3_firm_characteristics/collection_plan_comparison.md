# H3 수집안 비교 — Phase 1 최소안 vs 기존 전체안

> **[HISTORICAL — 2026-08-19 작성, 데이터 수집 착수 전 의사결정 메모]** 이 문서는 A안(PBR·배당수익률, KRX 전용)과 B안(ROE·시가총액·부채비율 추가, DART 병행) 중 Phase 1 범위를 정하기 위한 비교이며, 결론은 "Phase 1(A안)만으로 충분하다"였다. 실제로 구현된 노트북 09/10은 이 결론과 다르게 **DART 기반으로 부채비율·배당수익률·의약품 R&D를 수집**했고, **PBR과 ROE는 둘 다 수집하지 않았다** — A안·B안 어느 쪽도 그대로 채택되지 않았다. 현재 방법론은 `results/H3_firm_characteristics/summary.md`와 `H3_report.html`을 기준으로 한다. 이 문서는 의사결정 과정 기록으로만 참고할 것.

## 비교 전제

- 공통 범위: 7개 산업, 2016~2025(10개 연도), 산업별 기간평균 시가총액 Top10(최대 70개 기업)
- 공통 KRX 자료: 2025 산업 구성종목, 연도말 PBR·배당수익률·시가총액
- 공식 API 자동 다운로드 조건: `.env`의 `KRX_API_KEY`와 `유가증권 일별매매정보` API 이용승인. 키는 `AUTH_KEY` 헤더로만 전달한다.
- 공식 API 제공 범위: 연도말 시가총액. PBR·배당수익률·산업 구성종목은 Open API 미제공이므로 KRX 화면 다운로드 파일 11개(구성종목 1 + 연도별 평가자료 10)를 사용한다.
- 논리적 공식 API 요청: 성공 기준 연도별 1회, 총 10회. 휴장일이면 12월 31일부터 앞 거래일까지 날짜를 이동하며 완료 연도는 checkpoint로 skip한다.
- 실제 후보 기업 수를 `N`(최대 70), DART 대상 firm-year를 `F=N×10`(최대 700)으로 둔다.

## 시간 산정 방법

1. **최초 코드 구현 및 디버깅**: A안 수집기는 구현·오프라인 테스트 완료. B안은 기존 DART 코드가 있으나 실제 API 키와 실표본으로 통합 검증해야 하므로 고정 시간을 만들지 않는다.
2. **실제 데이터 다운로드**: 위 호출 수와 코드에 명시된 요청 간격으로 하한을 계산했다. KRX/공시 서버 응답시간과 차단·재시도는 사전에 확정할 수 없어 최초 실행의 시작·종료 로그로 실측한다.
3. **데이터 정제·검증**: A안은 자동 검증표를 확인한다. B안은 `collection_errors.csv`의 부분결측 건수와 계정 불일치 건수를 센 뒤 건당 확인시간을 곱한다.
4. **수기 작업**: B안 R&D는 약 50건이다. 먼저 5건 처리시간을 재고 `50 × (5건 평균시간)`으로 추정한다. 근거 없는 시간값은 두지 않는다.
5. **총 예상 작업량**: A안은 KRX 공식 API 성공 10회 + 화면 파일 11개 + 검증표 확인, B안은 여기에 DART 최대 1,401~2,101회 + R&D 약 50건 + 오류원장 검토가 추가된다.

## 연구 질문별 추가 효용

- **PBR**: 더 음(-)인 베타와 높은 PBR의 정렬은 장기 성장 기대와 일관적인지 보는 최소 근거다. 듀레이션을 직접 측정하거나 인과를 입증하지 않는다.
- **배당수익률**: 더 음(-)인 베타와 낮은 배당수익률의 정렬은 현재 배당보다 미래 성장 기대가 큰 특성과 일관적인지 본다.
- **ROE**: 성장주적 가격 특성이 실제 수익성과 함께 나타나는지 구분한다. 그러나 산업 7개에서 수익성이 베타를 통제한다고 말할 수는 없다.
- **부채비율**: 조달구조와 금리민감도의 정렬을 보지만 금융업의 예금부채 때문에 산업 간 비교가능성이 낮다. 핵심 질문에 대한 한계효용이 낮아 Phase 1 제외가 합리적이다.
- **시가총액**: 기업규모 차이를 보여줄 수 있지만 현재는 표본 선정·가중치·집중도라는 보조 역할이 더 중요하다. H3 설명변수로 넣지 않는다.
- **매출대비시총**: PBR과 다른 성장 프리미엄 관점을 더하지만 매출 정의·DART 결측 부담이 크고 PBR과 정보가 겹칠 수 있다. PBR 결과가 나온 뒤 확장 여부를 판단한다.
- **R&D**: 의약품의 장기 성장 논리를 직접 보강할 여지는 있으나 전 산업 비교가 아니므로 7개 산업 Spearman 변수로 쓰지 않는다.

결론적으로 Phase 1만으로 “7개 산업의 순위가 성장주적 특성과 같은 방향으로 정렬되는가”라는 모형 E 최소 질문은 완결된다. 전체안은 패턴의 성격을 더 세분하지만 표본 수나 인과 식별을 개선하지 않는다.

## KRX 자동화 범위와 차단 시 대안

- **자동화 가능**: 공식 `AUTH_KEY` API로 연도말 시가총액을 받고 원본 JSON·연도 checkpoint·실패 로그·재시도·검증을 자동화한다.
- **공식 미제공 범위**: 2026-06-01 KRX 공지에 따라 PBR·배당수익률·구성종목은 화면 검색/다운로드 또는 구매로만 확보한다. 공지가 금지한 pykrx 등 비공식 라이브러리는 사용하지 않는다.
- **현재 인증 상태**: 제공된 키의 공식 시가총액 API 스모크는 `401 Unauthorized Key`였다. KRX 포털에서 `유가증권 일별매매정보` API 이용신청 승인이 필요하다.
- **안정적인 실행**: KRX 화면 파일은 `config.KRX_MANUAL_DIR`에 두고 공식 API 수집기를 실행한다. 파서는 11개 파일을 표준화하고 누락 연도·산업·변수를 validation CSV로 검출한다.
