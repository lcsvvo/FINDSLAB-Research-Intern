분석 단계별 요약과 결과표·그림을 정리한 폴더다.

| 폴더 | 내용 | 요약 |
|---|---|---|
| `EDA/` | 기술통계·시계열·상관관계 | `tables/`, `figures/` |
| `Baseline_industry_beta/` | 산업별 금리베타와 산업 간 차이 | [summary.md](Baseline_industry_beta/summary.md) |
| `H1_yield_curve/` | 수익률곡선 요인과 신용스프레드 | [summary.md](H1_yield_curve/summary.md) |
| `H2_asymmetry_regime/` | 금리 상승·하락 비대칭과 정책국면 | [summary.md](H2_asymmetry_regime/summary.md) |
| `H3_firm_characteristics/` | 산업 재무특성과 금리베타의 관계 | [summary.md](H3_firm_characteristics/summary.md) |

각 폴더의 `tables/`에는 CSV 결과표, `figures/`에는 그림이 있다. 원자료는 포함하지 않는다.
