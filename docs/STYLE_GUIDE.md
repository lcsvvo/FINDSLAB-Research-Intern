# Documentation Style Guide

프로젝트 내 모든 Notebook과 Summary는 이 규칙을 따른다.
STEP 번호 체계와 이 형식은 이후 다른 연구 프로젝트에도 그대로 재사용한다.
템플릿: `docs/templates/TEMPLATE_analysis.ipynb`, `docs/templates/TEMPLATE_summary.md`.

## 1. 파일·제목 명명
- 노트북: `NN_stage.ipynb` (예: `01_data_preparation.ipynb`). 파일명에는 `STEP`을 쓰지 않고 두 자리 순번 + 단계명만 쓴다.
- 요약: `results/{카테고리}/summary.md` (예: `results/EDA/summary.md`)
- 결과물: `results/{카테고리}/{figures|tables}/{의미명}.png|.csv`
- 노트북 제목(H1)과 요약 제목은 `# STEP{N}. {제목}` 하나만 — 파일명과 별개로 문서 내부 표기에서만 STEP을 쓴다.

## 2. Heading 규칙
- `#` : 노트북당 정확히 1개(제목).
- `##` : 개요 블록(분석 질문·입력·출력), 분석 섹션, 해석, 요약.
- `###` : 목적, 관찰 결과, Takeaway.
- 레벨 건너뛰기 금지.

## 3. Markdown 규칙
- bullet은 1항목=1사실. 관찰과 해석을 한 bullet에 섞지 않는다.
- 강조(굵게)는 핵심 숫자·결론에만. 이모지·장식 사용 안 함.
- 리스트 앞에는 빈 줄을 둔다.

## 4. 개요 블록 (Notebook 첫 부분 통일)
노트북 첫 셀은 세 블록으로 구성한다.
- 분석 질문: 연구 질문 1~2문장 + 관련 가설.
- 입력: 입력 파일 + 이전 STEP 결과(있으면).
- 출력: Figure / Table / Summary 경로를 반드시 명시.

## 5. 코드 셀 규칙
- 코드 셀은 계산·그림 생성만 수행한다.
- 설명은 Markdown 셀에서만 작성한다.
- 코드에는 최소한의 주석만 둔다.

## 6. 관찰과 해석 분리 (필수)
- 관찰 = 데이터에서 직접 확인 가능한 사실(숫자·방향·패턴). 섹션마다 `### 관찰 결과`.
- 해석 = 관찰을 바탕으로 한 주장. 모든 섹션이 끝난 뒤 `## 해석`에 한 번만.
- 관찰에는 인과·의미 주장을 쓰지 않는다.
- 예)
  - 관찰: "전기전자 평균 수익률 0.000812로 최대, 철강금속 변동성 0.0184로 최대."
  - 해석: "산업마다 수익·위험 성격이 달라 금리 반응(베타)도 다를 여지가 있다."

## 7. Takeaway (필수)
- 모든 Notebook 요약과 Summary 최상단에 Takeaway를 작성한다.
- 핵심 결과·핵심 의미를 3~5줄로 압축.

## 8. 표·그림 설명
- 표: 바로 아래 인용구 1줄 — "이 표는 {무엇}을 보여준다. {takeaway 1문장}."
- 그림: 생성 셀 뒤 `### 관찰 결과`에 축·기간 1줄 + 읽히는 사실 1~3 bullet.

## 9. 출력 파일 규칙
- 결과 파일은 항상 같은 이름으로 저장하여 덮어쓴다(재실행 시 누적 방지).
- 파일명은 의미 기반으로 짓는다.
- 파일명에 날짜를 포함하지 않는다(변경 이력은 git으로 추적).

## 10. 재현성 원칙
- Notebook은 처음부터 끝까지 순차 실행하면 동일한 결과가 재현되어야 한다.
- 실행 순서에 의존하는 숨겨진 상태(hidden state)를 만들지 않는다.
- import·경로·시드 등 공통 설정은 Setup 셀에서 한 번만 정의한다.
- 모든 결과는 해당 Notebook만으로 재생성 가능해야 한다.

## 11. 분량 기준
- 목적 1~2문장 / 관찰 ≤4 bullet / 해석 2~4문장.
- 표·그림 캡션 = 설명 1문장 + takeaway 1문장.
- Summary ≤ 1페이지.

## 12. 부호 색상 규칙
- 부호가 있는 수치(계수·차이·수익률)는 그림·HTML에서 색으로 구분한다.
  - 음(−): `#c0392b` / 양(+): `#1f6feb` / 통계적으로 비유의: `#9aa0a6`
- p값·표본수·R² 등 부호가 없는 값에는 색을 쓰지 않는다.
- Notebook 마크다운에서는 `<span style="color:#c0392b">−0.02707</span>` 형태로 쓴다.
- 색만으로 정보를 전달하지 않는다. 부호·기호를 함께 표기해 색을 못 보는 환경에서도 읽히게 한다.
